# Code for a Billion 🇮🇳

A hackathon by **[Code for India](https://codeforindia.org)** — building technology that can impact a billion lives.

**Official IDE: [AgentFoundry (AF)](https://agentfoundry.me)** — participants build their projects in AgentFoundry.

> This repository is the **submission hub**. Every team submits their problem statement, code repo, and demo here.

---

## 🏆 How to participate

1. **Build** your project in **AgentFoundry (AF)** — the official IDE for the hackathon.
2. **Publish** your code to a **public GitHub repository** (include a README with setup steps).
3. **Record** a short **demo** — a live URL or a video (Loom/YouTube/Drive).
4. **Submit** here (next section).

## 📥 How to submit

Submissions are done through a **structured issue form** — no pull request or git skills required:

**→ [Open a new submission](../../issues/new?template=submission.yml)**

You'll be asked for:
- Team / project name and members
- **Problem statement** — what you're solving and for whom
- What you built (and how you used AgentFoundry)
- Your **GitHub repository URL**
- Your **demo URL** (live app or video)
- Track / category

Each submission becomes a public issue labelled `submission`, so everyone can browse the projects and judges can review them in one place.

Browse all submissions: **[Submissions »](../../issues?q=is%3Aissue+label%3Asubmission)**

## ✅ Submission checklist

- [ ] Built using **AgentFoundry (AF)**
- [ ] Public GitHub repo with a clear README (how to run it)
- [ ] Working demo link (accessible to judges)
- [ ] Submission issue filed here before the deadline
