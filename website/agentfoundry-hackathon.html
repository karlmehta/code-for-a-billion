How to participate

1

Build in AgentFoundry

Start your project in AF, the official IDE. Ideate, code, and iterate with agents.

2

Publish your repo

Push to a public GitHub repository with a README that explains how to run it.

3

Record a demo

A 2–3 minute video or a live link that shows the real thing working.

4

Submit on GitHub

One click — a structured form captures your problem, repo, and demo.

How you'll be judged

Four criteria, weighted equally — 25% each.

25%

Size of the problem

How many citizens face it — the larger the number affected, the higher the score.

25%

Severity of the problem

The level of human suffering, or the economic loss, the problem causes.

25%

Quality of the solution

How well it's designed and how effective it is at actually solving the problem.

25%

Proven impact

Actual deployment data — real evidence of impact in the field.
